Backup & restore

Everything in this app — products, stock, prices, photos, sales history, and wastage — lives only on this iPad, in this browser. Export a backup regularly and keep a copy somewhere safe (Files, email, iCloud) in case this device is lost, reset, or Safari's data gets cleared.

Restoring replaces everything currently in the app with the contents of the backup file — this can't be undone, so only restore a backup you're sure about.
